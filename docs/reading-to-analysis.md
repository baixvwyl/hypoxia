# 从本次阅读进入小鼠PDAC分析

日期：2026-11-16。本文件是基于文献审查整理的待验证研究方案，不是作者原始protocol，不含已运行的映射结果。

## 当前设计

| 内容 | 用户已确认 | 仍需记录 |
| --- | --- | --- |
| 分组 | T low / T high；T指T细胞浸润 | 度量、阈值、取材区域、测量平台及是否独立于待分析表达 |

跨模态配对的是小鼠，不是同一个细胞；T low与T high两组之间也不能因此当作配对设计。空间组间比较的独立重复为每组3只，不能用大量细胞扩增样本量。

## 当前最关键的决定

**先检查现有3CA产物，保留MP，不因NMF软件不同就推倒重做。**

| 已有产物 | 下一步判断 |
| --- | --- |
| 完整单鼠非负谱、usage、MP成员映射 | 核查基因空间和尺度；在训练鼠内构建可投射的共识谱，比较其与原MP的对应关系 |
| 已有共识非负权重矩阵 | 追溯其生成方法；确认它是可用于表达重构的谱，而非marker排序或有符号分数 |
| 只有每个MP的top genes | 可用于解释、匹配或基线评分；还不能直接作为starCAT数值参考，需回到原始NMF产物或重新建立参考 |

没有用户输出文件前，不能确认Omicos 3CA与starCAT的接口已经兼容，也不能给出可靠的自动转换脚本。程序匹配允许一对多或无法匹配，不强制一对一。

## 最小验证顺序

1. **先审查面板信息。** 对每个谱系/MP记录基因覆盖、权重覆盖、关键判别基因以及截取面板后的程序相似性。权重覆盖只是诊断，不能单独决定通过；没有适用于所有MP的统一最低基因数。
2. **整鼠留出。** 程序发现、共识参考、特征选择与阈值选择均只能使用训练鼠。用留出鼠完整表达和面板截取表达比较程序usage及可用标签；报告逐鼠结果，不能随机拆细胞后声称跨鼠泛化。
3. **区别两种验证。** 面板截取只测试丢失基因的影响，不能模拟Xenium探针效率、分割误差或转录本污染。真实Xenium还需要组织形态、独立marker及分割敏感性检查。
4. **避免配对泄漏。** 为某只鼠的Xenium产生评估用预测时，参考训练排除其scRNA数据；如最终用全部10只建参考，6只Xenium属于配对内部映射，不能标为独立外部验证。
5. **比较基线。** 在同样留鼠划分和基因限制下比较MP评分、适合的监督标签转移/分类与starCAT。连续MP恢复和离散亚型准确率是不同评估目标；不预设starCAT胜出。
6. **保留不确定性。** 记录拟合残差、程序可分性、基因扰动稳定性及低信息细胞。任何置信度阈值须在训练/验证阶段校准，不能把最大usage当分类概率。

参考构建应兼顾两组，保留跨鼠可复现性；批次处理与真实T浸润相关生物学差异分开审查。源码在传入的query中按基因计算缩放，因此每次投射包含哪些鼠、哪些细胞也会影响尺度；分样本与合并处理的选择须固定并做敏感性检查，不能默认可互换。

## 映射后才可评估的课题问题

在可靠的谱系与程序结果基础上，描述非T谱系程序与局部T浸润、肿瘤/间质区域及缺氧相关表型的关联。按切片构图，按鼠汇总；控制整体细胞组成后检查局部邻域富集。

T细胞丰度差异如果本身用于分组，就不是独立的新发现。表达推断的“缺氧程序”也不能直接等同组织氧含量或缺氧导致的机制；相关结论需要独立的缺氧测量或干预证据。当前文献支持的是方法评估路线，没有建立本项目的缺氧生物学结论。
